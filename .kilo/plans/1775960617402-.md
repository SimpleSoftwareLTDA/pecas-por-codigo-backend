## Problema: Clientes MCP não conseguem conectar (apenas SSE funciona)

Alguns clientes MCP não suportam a conexão inicial via SSE e precisam de HTTP puro.

### Solução: Usar protocolo STREAMABLE-HTTP

O Streamable-HTTP substitui o SSE e permite conexões HTTP normais (POST/GET), sendo mais compatível com diversos clientes MCP.

### Alteração necessária em application.yml:

```yaml
spring:
  ai:
    mcp:
      server:
        protocol: STREAMABLE  # Mudar de SSE (padrão) para STREAMABLE
        streamable-http:
          mcp-endpoint: /mcp  # Endpoint HTTP para mensagens MCP
          keep-alive-interval: 30s
```

### Remover configurações antigas de SSE:
As propriedades `sse-endpoint` e `sse-message-endpoint` não são mais necessárias com STREAMABLE.

### Nova estrutura recomendada:

```yaml
spring:
  ai:
    mcp:
      server:
        enabled: true
        protocol: STREAMABLE
        name: novo-pecas-online
        version: 1.0.0
        streamable-http:
          mcp-endpoint: /mcp
          keep-alive-interval: 30s
```

### Alternativa: Se quiser manter SSE e adicionar HTTP como fallback

Se ainda quiser manter SSE (para clientes que funcionam com ele), o Spring AI não suporta ambos simultaneamente nativamente. A recomendação é usar STREAMABLE que é mais moderno e compatível.
